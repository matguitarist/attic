## The same Help menu as every app

- **What's New in Attic** opens the latest release notes.
- **Report a Problem…** opens a new GitHub issue with the app version, build and macOS version already filled in.
- **Check for Updates…** is always in the Attic menu, greyed out when updates aren't available.
- **Show Log** (⌥⌘L) moved from the Window menu to the Help menu.
